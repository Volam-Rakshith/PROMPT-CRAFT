## 🌟 What is PromptCraft?

Unlike generic chatbots, **PromptCraft is specifically engineered to craft world-class prompts** for:
- 💻 **Coding & Architecture**: Prompts for Cursor, GitHub Copilot, Claude 3.5 Sonnet, ChatGPT Code Interpreter.
- 🎨 **Image Generation**: Photorealistic Midjourney v6, DALL-E 3, and Stable Diffusion prompts.
- 📈 **Business & Marketing**: Landing page copy, cold outreach, high-converting email sequences, SEO strategies.
- 🧠 **System Personas**: Custom instructions and system role definitions for LLMs.
- 🔬 **Research & Analysis**: Step-by-step problem breakdown, thesis validation, data extraction.

## 💡 How It Works

1. **Enter your topic or idea** into the terminal:
   - *Example:* `full-stack SaaS landing page for an AI accounting tool`
   - *Example:* `Python script to scrape real-time stock prices`
   - *Example:* `cinematic cyberpunk street photography in Midjourney`
2. **PromptCraft generates**:
   - 🎯 **The Master Prompt** (neatly packaged in a box with a 1-click **📋 Copy Prompt** button).
   - 🧠 **Prompt Strategy & Pro Tips** (role anchoring, context, strict negative constraints, output rules).
3. **Copy & Paste** directly into your target AI model (ChatGPT, Claude, Cursor, Midjourney)!

## 🚀 How to Host on GitHub Pages (60 Seconds)

1. Download the provided **`promptcraft-vr-developments.zip`** from the viewer and extract the files.
2. Create a new repository on [GitHub](https://github.com/new) (e.g. `promptcraft`).
3. Upload `index.html`, `style.css`, and `app.js` to the repository root.
4. Go to **Settings ➔ Pages** ➔ **Source: Deploy from a branch** ➔ **Branch: `main` / `(root)`** ➔ **Save**.
5. Your terminal prompt generator is live at:
   `https://<your-username>.github.io/<your-repo>/`

## ⌨️ Terminal Commands Reference

| Command | Action |
| :--- | :--- |
| `/help` | Display command manual |
| `/craft <idea>` | Quickly craft a prompt for any topic |
| `/types` | Choose from prompt archetypes (Coding, Midjourney, Marketing, Persona) |
| `/new` | Start a fresh prompt crafting session |
| `/history` | Open saved prompt library drawer |
| `/key <api_key>` | Set or change your Groq API key (`gsk_...`) |
| `/key` | Check current API key configuration |
| `/key clear` | Remove stored API key |
| `/models` | View available Groq models (`openai/gpt-oss-120b`, `openai/gpt-oss-20b`) |
| `/model <id>` | Switch model |
| `/theme <name>` | Switch palette: `dark`, `matrix`, `cyberpunk`, `amber`, `dracula` |
| `/export` | Download your crafted prompt library as Markdown (`.md`) |
| `/demo` | Toggle simulated demo mode |
| `/clear` or `/cls` | Clear the terminal screen |
